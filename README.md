# 📊 Tripleten Data Analysis Portfolio

Welcome! This repository contains a collection of data analysis projects developed during my training at Tripleten. Here, I apply Python, Pandas, and other analysis techniques to solve real-world problems.

## 📁 Project Structure

### 🔹 Sprint 1: Python Basics & Logic
* **Goal**: Practice fundamental programming concepts by processing and filtering arrays of user data.
* **Skills**: Python basics, loops, conditionals, and data structures.
* **[View Folder](./Sprint%201)**

### 🔹 Sprint 2: Music Preferences in Springfield and Shelbyville
* **Goal**: Analyze real data from a music streaming service to test hypotheses about user preferences in two different cities on different days of the week.
* **Skills**: Pandas, data filtering, and data manipulation.
* **[View Folder](./Sprint%202)**

### 🔹 Sprint 3: Exploratory Data Analysis (Instacart)
* **Goal**: Pre-process the data and perform Exploratory Data Analysis (EDA) on Instacart grocery delivery data to extract insights about customers' shopping habits.
* **Skills**: Pandas, data cleaning, handling missing values/duplicates, and Matplotlib.
* **[View Folder](./Sprint%203)**

### 🔹 Sprint 4: Statistical Analysis (Megaline Telecom)
* **Goal**: Analyze prepaid plan users' behavior (Surf vs. Ultimate) and determine which plan generates more revenue using statistical hypothesis testing.
* **Skills**: Pandas, statistical analysis, hypothesis testing (A/B testing), SciPy, and Seaborn.
* **[View Folder](./Sprint%204)**

### 🔹 Sprint 6: Games Popularity Analysis
* **Goal**: Analyze game sales data across different platforms and regions to identify patterns and predict future sales success to base a marketing campaign.
* **Skills**: Python, Pandas, Matplotlib, Seaborn, EDA, and statistical testing.
* **[View Folder](./Sprint%206)**

### 🔹 Sprint 7: Chicago Taxi Rides Analysis
* **Goal**: Understand the dynamics of taxi rides in Chicago, identifying top destinations, top companies, and testing the impact of weather on trip durations.
* **Skills**: Python, Pandas, data aggregation, hypothesis testing, and Matplotlib.
* **[View Folder](./Sprint%207)**

### 🔹 Sprint 8: App Usage & Marketing Analysis (Y.Afisha)
* **Goal**: Analyze user behavior, calculate product metrics (DAU, WAU, MAU, Retention), sales metrics (LTV), and marketing metrics (CAC, ROMI) to evaluate marketing investments.
* **Skills**: Pandas, cohort analysis, business metrics (LTV, CAC, ROMI), and data visualization.
* **[View Folder](./Sprint%208)**

### 🔹 Sprint 9: A/B Testing and Hypothesis Prioritization
* **Goal**: Prioritize business hypotheses using ICE and RICE frameworks, and perform a complete analysis of an A/B test for an online store to optimize revenue.
* **Skills**: Pandas, ICE/RICE frameworks, A/B testing, Mann-Whitney U test, and anomaly detection.
* **[View Folder](./Sprint%209)**

### 🔹 Sprint 10: Market Analysis for a Robot Cafe in LA
* **Goal**: Perform a market analysis of restaurants in Los Angeles using open data to support an investment pitch for a new robot-run cafe.
* **Skills**: Pandas, data cleaning, market analysis, Seaborn, and data storytelling.
* **[View Folder](./Sprint%2010)**

### 🔹 Sprint 11: User Journey and A/A/B Testing
* **Goal**: Map the sales funnel of a food product app to identify churn points and evaluate the impact of changing the app's font using an A/A/B test.
* **Skills**: Pandas, funnel analysis, A/A/B testing, Z-test for proportions, and Plotly.
* **[View Folder](./Sprint%2011)**

### 🔹 Sprint 12: Project Placeholder
* **Goal**: Project notebook currently under development or awaiting completion.
* **Skills**: Python, Pandas.
* **[View Folder](./Sprint%2012)**

### 🔹 Sprint 13: Customer Retention & Churn Analysis (Model Fitness)
* **Goal**: Analyze customer data to combat churn, develop a data-driven retention strategy, and use clustering to identify typical user behaviors.
* **Skills**: Machine Learning (Logistic Regression, Random Forest, K-Means), Pandas, Seaborn.
* **[View Folder](./Sprint%2013)**

### 🔹 Sprint 14 (Case 1): Inefficient Operators Identification (CallMeMaybe)
* **Goal**: Identify inefficient telephony operators based on missed calls, wait times, and active productivity to optimize workforce performance.
* **Skills**: Data Cleaning, Feature Engineering, KPI Creation, Tableau Data Preparation.
* **[View Folder](./Sprint%2014)**

### 🔹 Sprint 14 (A/B Test): Recommender System Evaluation
* **Goal**: Validate the experimental design and evaluate an A/B test for an international online store to determine if a new recommender system improves conversion rates.
* **Skills**: A/B Testing, Statistical Hypothesis Testing (Z-test), Plotly, Pandas.
* **[View Folder](./Sprint%2014)**
